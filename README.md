# 📱 AUL-Mobile-Repo - 移动端资源仓库

欢迎来到 **AUL-Mobile-Repo**。

### 📢 项目简介

本仓库是 **[UT-DR-AU-Launcher](https://github.com/znm2500/UT-DR-AU-Launcher)** 的**移动端专用**资源存储库。主要用于存放《传说之下》(Undertale) 及《三角符文》(Deltarune) 相关同人游戏的**移动端适配配置**、素材包、UI 资源以及版本更新数据。

> **注意：** 本仓库为启动器的移动端后端节点，**不建议**玩家直接手动下载或引用仓库内的原始文件。请通过我们的**官方移动版启动器**获取最佳体验，包括自动更新、资源校验及流畅运行。

---

### 🚀 开发者说明 (For Developers)

1.  **资源引用**：所有图片、音频等小体积资源通过 `jsDelivr` CDN 加速，移动端访问更稳定。
2.  **镜像下载**：大文件（如游戏数据包、补丁包）已接入 `Cloudflare` 边缘节点加速，缓解 GitHub 带宽压力，提升移动网络下载成功率。
3.  **移动端适配**：
    - 本仓库资源专为 Android / iOS 启动器优化，包含屏幕适配、触控配置及性能预设。
4.  **版权声明**：
    - 本仓库内的同人作品版权归原作者所有。
    - _Undertale_ / _Deltarune_ 版权归 **Toby Fox** 所有。
    - **严禁**将本仓库资源用于任何商业用途。
